# Taxonomy and Labels

Use these labels to keep entries consistent across the repository.

## Content Types

- `server pattern`: a reusable MCP server shape
- `workflow pattern`: a repeatable job-to-be-done flow
- `recipe`: a bundle of servers and workflows that suggests a product or internal-tool direction

## Status Labels

- `Pattern seed`: useful pattern-level content without a specific documented implementation
- `Documented example`: tied to a source, public implementation, or explicit case note

## Trust Levels

- `Low`: public or low-risk read-only context
- `Medium`: authenticated reads or limited writes with bounded blast radius
- `High`: local files, shell access, secrets, browser control, or production-affecting actions
