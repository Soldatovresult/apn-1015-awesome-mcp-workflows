# Submission Template

Copy this template when adding a new entry. Delete fields that truly do not apply, but keep the structure tight.

## Common Fields

```md
### Entry Title

- Type: `server pattern` | `workflow pattern` | `recipe`
- Status: `Pattern seed` | `Documented example`
- Summary:
- Primary user:
- Problem solved:
- Inputs:
- Outputs:
- Server mix or capability mix:
- Trust boundary:
- Human checkpoint:
- Why it matters:
- Evidence note:
```

## Claim Discipline

- If you do not have a source, keep the entry at `Pattern seed`.
- If you add a public example, say what the source proves and what it does not prove.
- Avoid unsupported adjectives such as "leading", "best", "widely used", or "production-grade".
